# Запара — планирование для преподавателей ОмГТУ

Сайт на Svelte и Vite. Списки преподавателей, групп, аудиторий и их расписания фронтенд получает только через backend API, который читает общий PostgreSQL-кеш. Worker постепенно обновляет этот кеш с API расписания ОмГТУ; браузер к этому API напрямую не обращается. «Консультации» и «Пересдачи» сопоставляют расписание преподавателей и выбранных групп. В «Заменах» выбирают преподавателя, чьи занятия нужно заменить, и возможных заменяющих поимённо или по тематической группе. «Рабочие встречи» показывают слоты, свободные у всех выбранных преподавателей.

В комиссионной пересдаче можно указать одного или двух конкретных преподавателей либо выбрать одну из шести тематических групп. ID участников групп сохранены в `src/lib/commission.ts` как `person` ID сервиса расписания, поэтому поиск каждого участника через API не требуется. Сайт загружает занятия только выбранной группы. Доступность комиссии отображается справочно и не блокирует выбор слота. Переключатель «Милосердие» исключает из доступных преподавателей тех, у кого нет пар в выбранный день. После построения таблицы переключатель пересчитывает доступность локально, без новых запросов и без сброса выбранных слотов.

В «Заменах» таблица показывает только занятия заменяемого преподавателя; учебные группы отдельно не выбираются. Можно указать любое количество конкретных кандидатов или одну тематическую группу. Доступность кандидатов также справочная и не блокирует выбор занятия. В выбранном занятии имена свободных преподавателей группы выводятся по одному в строке.

Во «Встречах» можно добавить любое количество преподавателей и выбрать период. Зелёные слоты свободны у каждого участника; если расписание хотя бы одного участника не загрузилось, слот не считается свободным. Подходящие слоты можно отмечать в таблице.

## Локальный запуск

Из корня проекта перейдите в папку сайта:

```bash
cd frontend
npm install
npm run dev
```

Для готовой статической версии:

```bash
npm run build
```

Файлы появятся в `frontend/dist/`.

## Сборка и запуск через Docker

Следующие команды выполняются из корня проекта. Файл `docker/Dockerfile.build` собирает сайт и экспортирует готовые файлы в `frontend/dist/`:

```bash
docker build -f docker/Dockerfile.build --target export --output type=local,dest=frontend/dist frontend
```

После этого запускайте основной nginx вместе с backend:

```bash
docker compose --env-file docker/backend.env -f docker/compose.backend.yaml --profile web up -d --build api web
```

Сайт будет доступен на порту `8080`. Этот nginx также проксирует `/backend-api` к FastAPI; отдельный frontend preview для production не используется.

## Важное ограничение

Браузер обращается только к `/backend-api`. Vite проксирует этот путь на локальный backend при разработке, а основной nginx — на сервис FastAPI в сети Compose при запуске через Docker. Backend читает расписание и справочники из PostgreSQL-кеша; только worker обращается к API ОмГТУ для постепенного обновления кеша.
